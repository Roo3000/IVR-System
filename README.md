# IVR System for Smallholder Farmers in Cameroon

Interactive Voice Response (IVR) system designed to give smallholder farmers easy access to critical agricultural information using basic mobile phones.

## Project Overview
This project was developed as part of my Master’s work in Computer Engineering.  
The system allows farmers to call a number and receive on-demand information about:

- Market prices
- Best agricultural practices
- Weather forecasts

It was graded **Excellent**.

## Key Features
- Voice-based menu system accessible from any basic phone
- Support for local language interaction
- Integration of agricultural data (crop dataset)
- Designed specifically for rural Cameroonian farmers

## Technologies & Tools Used
- IVR design & flow (Twilio / Autopilot style structure)
- JSON configuration (`agri-ivr.json`)
- Agricultural dataset processing (Excel)
- Voice response system architecture

## Repository Contents
- `agri-ivr.json` → Main IVR flow configuration
- `CROP DATASET.xlsx` / `CROP_DATASET.xlsx` → Agricultural data used in the system
